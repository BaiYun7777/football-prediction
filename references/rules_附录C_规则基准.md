## 一、🔴 投注决策六条原则（用户铁律 · 全局最高优先级）

**优先级高于任何其他规则。任何输出、筛选、推荐、报告都必须先过这六条。**

| # | 原则 | 规定 | 违反示例（严禁） |
|---|------|------|------|
| ① | **EV/凯利值不是判断依据** | 期望值 EV 与凯利值 f **只作价格参考展示**，严禁作为筛选、排序或投注门槛。判断"推不推"唯一看：情报可靠度 + 模型命中率 p | "EV 为负所以不推"、"凯利最高所以进 Top3" |
| ② | **赔率不设下限剔除** | 严禁剔除赔率 <1.8 的结果。**赚钱 ≠ 赚大钱**——低赔率高把握的"稳赢小钱"正是最该推的 | "赔率 1.46 太低，剔除"、"只推 2.0 以上的" |
| ③ | **情报可靠度是判断依据** | 每条判断标注确信度 **H**（多源确认）/ **M**（单源或部分存疑）/ **L**（源间冲突或不足）。**L 级不构成推荐依据**；高胜率方向必须立在 H/M 级情报上 | 用 L 级情报推高胜率方向而不降级；不标确信度 |

| ⑤ | **高胜率必核情报 · 小联赛不豁免** | 任何高胜率候选**必须**做基本面情报核实（伤停/状态/交锋/上季排名）。**禁止因联赛级别低（日乙/韩职/挪超/瑞超/巴甲/沙职等）缺省跳过**。确实无法检索到时才如实标注「未检索到」并下调确信度，**严禁编造** | "小联赛信息少，直接不分析" |
| ⑥ | **模型命中率 p < 61% 不做重点推荐**（v3.6.0-r18 上调 60→61） | "重点推荐"档（Top3 / 主推 / 串关主推腿）**准入三联判定：p ≥ 61% ∧ 情报双向 H/M 核验通过 ∧ 无洲际赛事周前强利空**（按 A1 拆分后净调整 ≤ −8pp 视为"强利空"）。p<61% 的场次**保留全景表展示**，但绝不进入重点档 | 把 p=55% 的"半稳胆"当 Top 推；p≥61% 但情报单边 / 欧战周前仍无脑顶格 |

**推荐输出的标准格式**（每场必带）：

## 三、🌏 洲际赛事周前降权（v3.3.0 按「赛程密度差」拆分）

**触发窗口** = 洲际比赛日前 **0-5 天**的国内赛事。
**覆盖赛事**：欧冠 / 欧联 / 欧协 / 亚冠精英（ACLE）/ 亚冠二级（ACL2）/ 解放者杯。

### A1 · 拆为"本方负荷"与"对方负荷"两条独立项，各自计分后求和（非取其一）

| 项 | 场景 | 调整 |
|------|------|------|
| **① 本方负荷** | 本队 3 天内打过洲际赛（含客场） | 主推方向 **−8pp** |
| | 本队 **客战**洲际归来 **且** 本场又是客场 | 主推方向 **−10pp**（叠加体能 + 旅途） |
| | 本队洲际赛为 ACL2 / 欧协 / 次级赛事 | 上述幅度 **减半** |
| **② 对方负荷** | 对手 3 天内打过洲际**客场** | 主推方向 **+4pp** |
| | 对手 3 天内打过洲际**主场** | 主推方向 **+2pp** |
| | 对手洲际赛为 ACL2 / 次级赛事 | 上述幅度 **减半** |
| **③ 互碰周（双方都有）** | 双方均在窗口内 | **净效应按 0 处理，不叠加**（由 A2 接管平局 +8~10pp） |
| **④ 叠加上限** | ①② 求和后 | 净调整 **不优于 +4pp、不劣于 −10pp** |
| **⑤ 让球深盘** | 本方负荷 ① 触发 **且** 让球 ≥1 | **维持直接警示禁碰**（此条不受深盘规则 A 档放宽豁免） |

**与 A2 的边界（消歧）**：只要**双方**均在 0-5 天窗口内 → 走 ③，不再单独适用 ① 或 ②；仅**单边**有洲际任务时，才适用 ①②。

**单边场景下的"强强对话"**：仅一方有洲际任务时，若双方同档（德比/榜首战），本方负荷按 **−5pp**（而非 −8pp）、对方负荷按 **+4pp** 照常适用。

### A2 · 洲际前"双参赛队互碰"特殊规则

双方在 0-5 天后**均有**洲际任务 → 各自留力概率高 → **平局概率 +8~10pp、总分倾向小**；不适用单边"强队降权"。**触发时 A1 的 ①② 项一律不适用**（净效应已归 0）——避免叠加导致过度压低。判据以"双方是否均在 0-5 天窗口内"为准，不区分赛事级别。

## 四、📉 让球深盘陷阱规则（v3.2.2 立规 · v3.3.0 三档化 · v3.3.0-r1 修订）

> **修订依据（2026-09-13）**：本周 5 场深盘暴露"单阈值刀太粗"——**极端深盘（HAD ≤1.20）穿盘是常态，中深盘才是真陷阱**。
> 标定样本：多特 1.18 让-2 赢盘率 18.0% 实际 **3-0 穿**（漏）、卡萨皮亚 1.16 受让+2 赢盘率 31.4% 实际 **1-4 穿**（漏）、切尔西 1.12 让-2 赢盘率 19.4% 实际 2-2 **未穿**、毕尔巴鄂 1.29 让-1 赢盘率 45.6% 实际 1-1 **未穿**、利物浦 1.37 让-1 赢盘率 43.3% 实际 0-0 **未穿**。

### 定义

竞彩对热门强队开出深让球盘（-1 / -1.5 / -2）时，"强队赢球"≠"赢盘"：
- 让 1 球：净胜 **2+** 才赢盘；净胜恰 1 球 → **走盘退本金**；平/负 → 输盘
- 让 1.5 球：净胜 2+ 赢盘；净胜 1 球 → 输盘
- 让 2 球：净胜 3+ 赢盘；净胜 2 球 → 输盘

### 🆕 三档判据（判定前必须先定档）

| 档位 | 条件（满足任一即入档） | 处置 |
|---|---|---|
| **A · 极端深盘** | ① 让球方 HAD ≤ **1.20**；或 ② 联赛档位差 ≥2 级 **且** 对手为垫底/升班马 | **允许小注（≤1 注，试验性）**；**可进串关**（v1.7）；保留平局风险标注 |
| **B · 中深盘** | HAD 在 **1.20–1.45** 区间，且让球赢盘率 < **42%** | **维持不投**（原规则 1-2 生效） |
| **C · 陷阱区** | 满足 **B 档**（HAD 1.20–1.45）的深盘 **且** 爆冷 Tier ≥2 **且** 模型平局概率 ≥**18%** | **强制不投主胜方向（含串关）** |

**🔴 定档顺序（v3.3.0-r1 修订）：先判 A → 再判 B → 最后判 C（A 优先）**
- **A 档优先于 C 档**：若已定档为 **A**，**不再进入 C 档剔除**，直接走 A 档试验小注通道；
- **C 档仅对未入 A 档的深盘（HAD >1.20）生效**，即 C 档的适用区间是 **B 档区间**；
- **C 档优先于 B 档**：B 档区间内若同时满足 C 档条件，按 C 档处置（更严）。

> **r1 修订依据**：原「A→C→B、C 优先」导致 A 档被完全架空——30 场中深盘 6 场（HAD 1.11–1.20）**全部判 C 档（100%）**，A 档 0 触发，三档化实质退化为单档；且 009 多特 3-0、030 皇马 4-1 两场实际大穿盘被 C 档误剔除。故**将 A 档从 C 档管辖中解放**，并将 C 档平局阈值由 15% 上调至 **18%**（实测 6 场深盘模型平局最低 19.6%，15% 无区分度）。


**A 档试验性条款（重要）**：A 档当前仅 **2 例**正向标定（009、025），**累积至 ≥8 例后方可转正式**。在此之前：
- 单场限 **≤1 注**；
- 必须在方案中显式标注「**A 档试验性 · 样本不足**」；
- 若同窗口出现 ≥2 场 A 档，**可全部入稳单 Top3**（v3.4.7-r1 用户裁决：取消「只取 HAD 最低一场」限制），按排序主键竞争名额；单场 ≤1 注与「A 档试验性·样本不足」标注不变。

### 强制规则（方案生成时必须执行）

1. 凡让 1 球赢盘率 <45% 的场次（用 `poisson-calc.py` 让球盘输出核实），**强制标注「深盘陷阱」**并明确"不投让球方向"——**但须先按三档判据定档，A 档按上表处置**；
2. **边界分级（并入 B 档）**：满足「强队主场 + 实力断层≥2.5（联赛档位差≥2级 或 Elo差≥250 或 身价比≥5x）+ 无核心伤停（非S1）」时，可小注边界放宽至 **赢盘率 ≥42%**；**其余场景维持 <45% 强制不投**。本条的适用前提是**已定档为 B**；
3. 若竞彩对该场**限制胜平负单关/不可投**，**不要因此转向让球深盘**——这是机构防热门单关的结构性设计；
4. 数据参考（模型实测让 1 球赢盘率）：曼联 34% / 费耶诺德 36.8% / 尤文 36.4% / 国米 47% / 波尔图 45.3%；

### obs-1 · 深盘加严（观察版 · 待阈值回测后定）
- **触发**：竞彩胜平负 ≤1.15，或去水隐含 p ≥80%（阈值待定，见 obs-6）
- **若未来生效时**：三联判定第二条由「情报 H/M」升级为 **「情报必须 H 级 ∧ 独立第二口径验证」**
  - 独立第二口径 = 泊松自算 / H2H / 防守数据三角互证；**禁止直接引用市场定价充当模型 p**
- **⚠️ 本项不是"深盘禁止推荐"**：EV 层面深盘衰减**最小**（005 场次 1.12 的 EV 仅 −1.4%，符合 favourite-longshot bias）。真实风险仅两条：①作串关胆时增益 12% 却承担 8.8% 全串归零；②p 直接抄市场导致盲从（本场真正死因）

### obs-2 · 洲际窗口维持 0-5 天（❌ 已否决）
- 提案：A1 窗口 0-5 天 → 0-7 天。**裁决：否决，维持 0-5 天。**由单场 6.5 天倒推属过拟合。

### obs-3 · 新援首发 ≥2 人降档（❌ 不立规则）
- **裁决**：略显刻意、泛化能力差，不设自动触发。后续仅作人工判断参考。

### obs-4 · "洲际前最后一战"独立标记（⏸ 观察）
- 无论是否在 0-5 天窗口内，若该队下一场为洲际赛事，在基本面中**标注**（不作扣减）
- **升级条件**：累计 **≥3 例**"窗口外（6-7 天）洲际前爆冷"样本再议入规则

### obs-5 · 情报矛盾处理：模板内容 vs 事实陈述（✅ 立即执行的口径）
- **已确认失误**：周一004 赛前将"卡尔马头号射手 Rosenqvist 转投佐加顿斯"判为不可靠，实际属实
- **执行口径**：信息源内部冲突时，**保留事实陈述、丢弃模板生成内容**（首发名单多为模板产出；转会 / 伤停 / 停赛为事实）

### obs-6 · 得势不得分模式权重（⏸ 观察）
- 48 小时内 2 例：利雅新月 17 射 0 球、卡尔马 13 射 1 正 0 球
- **当前动作**：赛前若候选方近 3 场出现"控球 ≥55% 且进球 ≤1"，在基本面中**显式标注**（暂不改 λ 系数）

### obs-7 · 胜率口径固化 + EV 同源 + 赔率时效（✅ 立即执行的口径）

> **事故**：同一天内，对话侧把竞彩去水共识 74% 抄成"模型 p=75%"（**市场盲从在复盘当天复发**）；推送侧 EV 标 +0.04 与自身 p=60.1% 矛盾（实为 −27.9%），且完整版沿用 09:45 过期赔率。

1. **三口径标签化（必做）**：任何"胜率/命中率 p"必须标注口径 —— `模型p`（泊松+全部修正后的独立估算）/ `共识p`（去水市场共识）/ `毛p`（1/赔率，含抽水，**禁对外**）。**模型p 与 共识p 并列展示；禁止单独输出不标口径的"胜率 XX%"；禁止用共识p/毛p 直接充当模型p。**
2. **模型p 必须先独立、后对比**：先跑泊松+爆冷修正得独立 p，再与共识对比。|模型p − 共识p| > 2.5pp → 强制复核；**复核后仍 >2.5pp → 该方向强制降为观望/注明非稳单**。
3. **EV 唯一同源公式**：`EV = p模型 × 赔率 − 1`，p 必须与展示的模型p 同源同值。禁止混用共识p/毛p/初版p 算 EV。
4. **赔率时效（必做）**：每场记录赔率**发布时间**并取最新值分析；分析期间任一方向赔率单边变动 **≥8%** → 触发**调赔预警**：① 用最新值重算共识与 EV；② 报告单独成段说明；③ **调赔方向与推荐方向相悖时，该场不得列 Top1/Top2**。
5. **两阶段一致性**：完整版发布前必须复查简版赔率是否已更新；更新则全量重算并在「Top3 调整说明」中写明"赔率已变动"。

### ⚠️ 三条硬口径
1. **单关标志必读**：正确来源为 `poolList[]` 的 `single`；顶层 `bettingSingle` 恒为 0，**禁用**。任何"单关 @X"的方案，若未核 `poolList` 的 `single` 字段即为**事实性误报**。
2. **胜平负可能未开售**。深盘场次 HAD 常为 `-`，只有让球盘可买。分析前先确认哪个盘口有值。
   - **🔴 处置强制（v3.4.3-r1 · 2026-09-19）**：`had` 缺失/为空 **且** `hhad` 有值 → **仅让球盘**，方向须填**让球方向**、`HAD` 列填 `—`、**不得进单关榜**、须标注「本场仅让球盘可买」；`had` 与 `hhad` **双缺失** → **剔除出候选池**，且在 `[覆盖度校验]` 剔除清单中列明。**严禁用 `hhad` 冒充 `HAD`、严禁按胜平负口径输出无盘口场次。**（实测 2026-09-19：4 场 `had={}`，`poolList` 仅含 HHAD）
3. **竞彩让球是整数盘，三档无走水**，且"受让方那一档吃掉平局"：让 +1 →「主胜」档 = **主队不败**；让 −1 →「客胜」档 = **客队不败**。**最易搞错**：把让球档当亚盘解读，会把"不败"误读成"净胜 N 球"。

4. **🔴 HAFU 池状态判定（v3.5.0-r1 · 周三002 事故）**：HAFU 是否可评估**只看 `poolList[].hafu` 池状态**（无 hafu 池 / poolStatus 非在售 / 无 odds = 未开售）；**「无 HAD 盘（胜平负未开售）≠ HAFU 未开售」**——池在售而无 λ 时走纯市场核算（九格去水），严禁标「未开售」。校准案例：周三002 日本亚 vs 泰国亚（09-22），HAD 未开售、hafu 在售（胜胜 1.32，九格水位 20.5%）。
